# Orderumbi

Orderumbi adalah situs web untuk memperkenalkan produk UMBIKLIK dan
memudahkan pengguna melakukan pemesanan melalui WhatsApp.

## Demo

Demo aplikasi dapat diakses melalui GitHub Pages:

(https://raihanedbagaskoro.github.io/orderumbi/)

## Tujuan Proyek

Proyek ini bertujuan membantu usaha atau kegiatan kewirausahaan mahasiswa
menampilkan informasi produk dan menyediakan proses pemesanan yang sederhana.

## Fitur

- Menampilkan informasi produk UMBIKLIK
- Menampilkan pilihan produk
- Formulir pemesanan
- Integrasi pemesanan dengan WhatsApp
- Tampilan responsif untuk perangkat seluler

## Teknologi

- HTML5
- CSS3
- JavaScript
- GitHub Pages
